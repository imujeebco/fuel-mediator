# FuelPay Mediator

Central, multi-station mediator between the FuelPay worker app, PTS-2 pump controllers and Odoo 18 (`odoo_pts_bridge*`).
It is planned as PHP / Yii3 / MySQL 8 (InnoDB) with a transactional outbox and PHP CLI workers.

**Status:** Phase 0 (discovery) complete. No application code yet. Start with [docs/progress.md](docs/progress.md).
